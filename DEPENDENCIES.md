# Залежності viral-video-lab

Плагін постачає власні агенти, скіли й скрипти. Сторонні скіли, програми та конектори в репозиторій не копіюються: їх перелік лежить у `config/dependencies.json`, а наявність перевіряє `scripts/check_deps.py` (або скіл `viral-lab-setup`).

Етапи конвеєра: 0 бриф, 1 пошук трендів, 2 відбір топ-5 і завантаження, 3 аналіз руху, 4 маркетинговий аналіз, 5 рада рецензентів, 6 синтез, 7 відтворення, 8 контроль якості.

Перевірка: `py -3.12 scripts/check_deps.py --manifest config/dependencies.json` (код 0, коли всі обов'язкові залежності є).

## Обов'язкові

### `watch`
Скіл: завантажує відео через yt-dlp, нарізає кадри ffmpeg і витягує транскрипт. Ставиться в `~/.claude/skills/watch`. Потрібен на етапах 3 і 8. Без нього не вийде проаналізувати відео та перевірити результат.

### `yt-dlp`
Програма для завантаження відео. Windows: `winget install yt-dlp.yt-dlp`. Потрібна на етапі 2. Без неї не завантажаться відібрані ролики.

### `ffmpeg`
Програма для обробки відео й аудіо. Windows: через winget. Потрібна на етапах 2, 3, 8. Без неї немає кадрів, нарізки та перевірки фінального відео.

### `ffprobe`
Входить до складу пакета ffmpeg, ставиться разом з ним. Потрібна на етапах 2, 3, 8: читає тривалість, розмір і частоту кадрів. Без неї не перевіряються технічні параметри відео.

### `hyperframes`
Плагін Claude Code з marketplace `heygen-com/hyperframes`. Потрібен на етапі 7: збирає відео з HTML. Без нього неможливо відтворити ролик.

### `metrics-source`
Конектор claude.ai: ScrapeCreators або vidIQ (достатньо одного), вмикається в налаштуваннях конекторів застосунку. Скрипт його не бачить (статус «вручну»), тому його перевіряє скіл `viral-lab-setup`, шукаючи інструменти за закінченням імені (`v1_account_credit_balance` або `vidiq_balance`). Потрібен на етапі 1. Без нього немає метрик трендових відео.

## Додаткові

### `reference-video-replica-qc`
Скіл порівняння репліки з референсом. Етап 8. Без нього контроль якості обходиться власними перевірками. На етапі 3 не використовується: там референс аналізують сам по собі, репліки ще не існує, тож порівнювати ні з чим.

### `ffmpeg-skill`
Скіл-довідник з команд ffmpeg. Етап 8 (експорт `final/<платформа>.mp4`). Без нього команди складаються без підказок. На етапі 2 не використовується: завантаження робить yt-dlp, а перевірку — сам `ffprobe`.

### `last30days`
Скіл огляду подій і трендів за останні 30 днів. Етапи 1, 4. Без нього тренди шукаються лише через конектор.

### `social`
Скіл для контенту соцмереж. Етапи 4, 5. Без нього слабшає маркетинговий аналіз.

### `ad-creative`
Скіл для рекламних креативів і хуків. Етапи 4, 5. Без нього слабшає аналіз хуків.

### `ads`
Скіл про рекламні кампанії. Етапи 4, 5. Без нього слабшає маркетинговий аналіз.

### `video-editing`
Скіл монтажу відео. Етап 7. Без нього відтворення йде без монтажних підказок.

### `video-prompting`
Скіл промптів для генераторів відео. Етап 7. Без нього сцени для генераторів описуються простіше.

### `higgsfield`
Скіл для Higgsfield AI. Етап 7. Без нього не доступний цей генератор.

### `threejs`
Скіл для 3D-сцен у браузері. Етап 7. Без нього відсутній варіант 3D-відтворення в Three.js.

### `text-to-blender`
Скіл керування Blender мовою запитів. Етап 7. Без нього відсутній варіант 3D-відтворення в Blender.

### `remotion-best-practices`
Скіл про Remotion. Етап 7. Плагін Remotion на цьому ПК підключено через акаунт і в `installed_plugins.json` його немає, тому перевіряється саме скіл. Без нього відсутній варіант збирання відео в Remotion.

### `whisper`
Програма розпізнавання мовлення. Очікується в `~/whisper-env/Scripts/whisper.exe`. Етап 3. Без неї транскрипт береться з субтитрів або хмарного сервісу.

### `node`
Node.js. Етап 7 і публікація. Без нього не запускаються інструменти на Node.

### `git`
Git. Етап 7 і публікація. Без нього немає версіонування й публікації результатів.

### `gh`
GitHub CLI. Windows: `winget install GitHub.cli`, типовий шлях `C:/Program Files/GitHub CLI/gh.exe`. Етап 7 і публікація. Без нього не працює публікація на GitHub з терміналу.
